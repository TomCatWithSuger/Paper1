# B1/B2/B3 波形域评估结果与分析说明

> 更新时间：2026-10-13
> 本文汇总 Mel 域统一评估与波形域（声码器）评估的全部结果、结论与运行情况。实验设计背景见 `docs/B1_B2_B3统一评估说明.md`。

## 1. 背景与任务

B1（条件 Flow Matching）、B2（一步条件 MeanFlow）、B3（MeanVoiceFlow）训练目标不同，训练 loss 不可横向比较，结论必须来自统一生成评估。

Mel 域统一评估（6 个实验 × 100 组 source/reference）完成后，遗留的核心问题是：

1. B2 的 1 NFE 能否接近 B1 的 50 NFE？
2. B1 的生成质量如何随 NFE 变化？
3. B3 相比 B2 是否改善一步生成质量？
4. Mel 指标与人耳感知（波形可懂度、韵律、音色）是否一致？

为此接入统一冻结声码器，把所有生成 Mel 转为波形，补充可懂度（WER/CER）、说话人相似度、F0/能量韵律和 RTF 指标。

## 2. 评估设置

### 2.1 波形域评估管线

- 声码器：BSC-LT/vocos-mel-22khz，冻结预训练 Vocos（80 维 Mel → 22.05 kHz 波形），**所有系统统一使用**，论文表述为 _"We use a frozen pretrained Vocos vocoder for all systems to convert generated Mel-spectrograms into waveforms."_
- Mel 适配：项目 log 功率 Mel ÷2 转对数幅度，经 HTK→slaney 频带线性插值后送入 Vocos（clamp 到 log(1e-7)）。
- 可懂度：openai/whisper-small 英文转写，文本归一化后计算词/字符编辑距离（WER/CER）。
- 说话人相似度：MeanVC 冻结 WavLM Large + ECAPA-TDNN，256 维 L2 归一化嵌入余弦相似度（生成语音 vs 参考语音）。
- F0：torchaudio `detect_pitch_frequency`（60–500 Hz，帧长 0.01 s），双侧有声帧（≥10 帧）log-F0 相关与 MAE。
- 能量：1024/256 分帧 log-RMS 的相关与 MAE。
- RTF：声码器 RTF 单独统计；端到端 RTF =（Mel 生成延迟 + 声码器解码延迟）/ 音频时长，不含离线 MeanVC 特征提取。

### 2.2 样本规模

- 生成样本：6 个实验 × 100 组配对 = 600 条；
- 重建对照：100 条真实参考 Mel 经同一适配链路与 Vocos 重建（评估声码器链路本身）；
- 所有逐样本指标与生成波形均已保存，可试听核对。

## 6. 关键发现

### 6.1 Mel L1 不能作为系统对比主指标

B2 与 B1-50 的 Mel L1 几乎完全相同（2.9306 vs 2.9325），但波形 WER 是 1.00 vs 0.36；B3 的 Mel L1 略优于 B1-50（2.9188 vs 2.9325），WER 却更差（0.47 vs 0.36）。Mel 距离只衡量逐帧声学贴近度，无法反映相位结构、可懂度与韵律，甚至偏向过平滑输出。论文应以波形域指标为主、Mel 距离为辅。

### 6.2 B2 一步生成在波形域彻底失败（对应"情况 B"）

100 样本规模确认：B2 WER ≈ 1.00（Whisper 转写内容完全错误）、CER 0.68、说话人相似度最低（0.116）。这不是质量略降，而是内容层面的崩坏。判定为统一评估文档预设的**情况 B**（B2 1 NFE 明显差于 B1 50 NFE），且比预想更严重。后续重点：条件利用、训练/推理先验不一致（见 B3 说明 16.2）、trajectory refinement。

### 6.3 B1 的 NFE 权衡反直觉

NFE 越高，Mel L1 与 WER 反而越差（WER 0.23→0.36），但 F0 相关大幅改善（0.22→0.65）。解释：1-NFE 输出过平滑，对 ASR 友好但音高轨迹几乎不对；更多 NFE 恢复韵律细节的同时引入 ASR 敏感的伪影。因此 **B2/B3 的公平波形基线应是 B1 50-NFE**（同为 Mel L1≈2.93，韵律已恢复），不能用 1-NFE 的"低 WER"证明一步方法可懂度好。

### 6.4 B3 改进有效但不充分

B3 相比 B2：WER 1.00→0.47、说话人相似度 0.116→0.166、F0 相关 0.666（全系统最好）。混合伪源先验和源扩散时间确实缓解了崩坏，但可懂度仍差于 B1 任意 NFE，音色迁移没有实质改善。

### 6.5 说话人相似度是系统性短板

所有转换系统 0.12–0.23，对照上界 0.82，差距悬殊。两种可能：转换确实没有迁移好音色，或生成音质下降导致 ECAPA 嵌入不可靠（B2 崩坏同时 WER 与 spk_sim 最低，支持后者有贡献）。论文需如实讨论，并可补充试听证据。

### 6.6 效率

1-NFE 系统端到端 RTF ≈ 0.002（B1-50 为 0.030），约 14 倍加速；全部系统远快于实时。MeanFlow 的效率收益是成立的，问题只在质量。

## 7. 结论

1. **MeanFlow（B2）当前不适合直接用于 VC**：一步推理快，但波形内容崩坏。
2. **B3 的设计方向有效**（f0 最好、WER 大幅优于 B2），但未达到可用水平，是后续改进的主要基线。
3. **Mel 指标与波形指标结论不一致**，这是论文方法论上的重要论点：一步生成/平均速度类方法的评估必须做到波形域。
4. 若做公平对比：B1 应报告 NFE 曲线（1/5/10/50），突出其韵律-可懂度权衡，而不能只报单点。

## 8. 运行情况

- 全量评估分两段完成：GPU 0 在第 288 个样本时发生 GSP 固件挂死（dmesg Xid 175 → Xid 154 GPU Reset Required），属驱动/固件层故障，与评估代码无关；GeForce 不支持 `nvidia-smi --gpu-reset`，只能重启恢复。
- 挂死后驱动将故障卡移出 CUDA 设备表，`CUDA_VISIBLE_DEVICES=0` 实际映射到健康的物理 GPU 1，评估程序按 `(experiment_id, source_id, reference_id)` 断点续跑至全部完成（600 + 100 = 700 条）。
- 残留僵尸进程重启后自动清除；GPU 0 需与同机用户（hyt、pl）协调重启恢复。

## 10. 边界与注意事项

- WER/CER 受 Whisper 转写与文本归一化影响，对照上界（0.038）已量化该链路噪声；系统间比较有效，绝对值不宜与使用其他 ASR 的文献直接比。
- 说话人相似度使用 MeanVC 内部冻结 ECAPA 编码器，与部分文献的 SECS 编码器不同，跨论文数值不可直接比较。
- Mel 适配（log 功率→幅度、HTK→slaney）是近似映射，其损失已包含在重建对照中。
- F0 使用 torchaudio 自相关法，非 CREPE 等学习型提取器。
- RTF 不含离线 MeanVC 特征提取（与统一评估口径一致）。
- 生成过程非确定性（B3 每次重新采样噪声），本次每对样本只生成一次；论文正式报告建议补多次采样均值±方差或显著性检验。
