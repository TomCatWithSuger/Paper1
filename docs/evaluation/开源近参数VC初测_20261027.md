# 接近B1参数量的开源VC初测

开始：2026-10-26；完成：2026-10-27。已实际测试两个官方预训练系统：MeanVC和MeanVC2，没有训练新模型。候选来源和下载指纹见[筛选记录](../research/%E5%BC%80%E6%BA%90VC%E8%BF%91%E5%8F%82%E6%95%B0%E6%A8%A1%E5%9E%8B%E7%AD%9B%E9%80%89_20261026.md)。Seed-VC Tiny（25M）作为候选保留，本轮未下载或测试。

## 1. 范围与统一口径

从P1原100对中，固定seed=20261026，每位源说话人随机选2句，共10位源说话人、20个原配对。使用原始源/目标音频；B1的1/50步、B3的1步复用已存WAV。两个官方模型各测两种步数，新生成80条；七配置共140条全部重新使用同一Whisper-small和独立CAMPPlus评分。表中CER/WER是逐句均值，相似度是CAMPPlus余弦分数，不能与P1原WavLM相似度直接横比。

这是公开预训练成品的能力对照，不是等训练数据/预算的算法消融。外部权重是否见过VCTK评估语料未核实；不能据此宣称泛化优劣。只有一次固定生成噪声，未做听测。

## 2. 实测结果

| 配置             | 生成器/条件投影参数 | CER↓   | WER↓   | 目标相似度↑ | 源相似度 | T−S↑   |
| ---------------- | ------------------- | ------ | ------ | ----------- | -------- | ------ |
| B1，整句1步      | 18.74M              | 8.56%  | 12.51% | 0.4019      | 0.2787   | 0.1232 |
| B1，整句50步     | 18.74M              | 13.62% | 22.47% | 0.5580      | 0.3958   | 0.1622 |
| B3，整句1步      | 18.87M              | 20.78% | 34.19% | 0.4983      | 0.4161   | 0.0821 |
| MeanVC，每块1步  | 14.06M              | 23.45% | 41.47% | 0.5646      | 0.3321   | 0.2325 |
| MeanVC，每块2步  | 14.06M              | 16.59% | 28.08% | 0.5884      | 0.3716   | 0.2169 |
| MeanVC2，每块1步 | 17.71M              | 3.73%  | 6.14%  | 0.7650      | 0.3948   | 0.3701 |
| MeanVC2，每块3步 | 17.71M              | 3.69%  | 6.44%  | 0.7809      | 0.4128   | 0.3681 |

参数只统计转换网络及其可训练条件组件，不含冻结ASR、WavLM说话人编码器和声码器。MeanVC/MeanVC2均严格加载全部转换权重；说话人分支无缺失键，唯一未使用键是训练分类头。

| 载入组件参数        | MeanVC  | MeanVC2 |
| ------------------- | ------- | ------- |
| 转换网络及条件模块  | 14.06M  | 17.71M  |
| ASR前端             | 21.68M  | 57.39M  |
| 说话人前端，含WavLM | 323.86M | 323.86M |
| 原生声码器          | 8.29M   | 8.29M   |

这是模型对象的参数计数，不表示所有参数都在每次前向中执行。MeanVC2的生成器接近B1，但不能称为整系统规模相同。条件信息预算也不同：MeanVC直接使用目标参考Mel，B1/B3/MeanVC2的这里所测路径主要使用全局目标说话人向量；原P1参考与源同文本，因此不能把差异只归因于生成器。

| MeanVC，每块1步  | +14.8887 [+0.6254, +33.6820] | +0.1093 [-0.1292, +0.2544] |

| MeanVC2，每块1步 | -4.8344 [-11.6853, +2.0529]  | +0.2470 [+0.1451, +0.3828] |

源说话人×目标说话人×实际文本乘积重采样5000次；只有20个源语句、10个源说话人，未校正多重比较，不包含训练种子方差。负CER差表示内容指标更好；正T−S差表示相对目标偏好更强。区间跨零时不宣称该差异稳定成立。

## 4. 速度与流式调用口径

| 配置             | 全句实际DiT调用数范围 | 生成+声码器均值，秒 | 输出/源时长比均值 |
| ---------------- | --------------------- | ------------------- | ----------------- |
| MeanVC，每块1步  | 18–42                 | 0.794               | 0.987             |
| MeanVC，每块2步  | 36–84                 | 1.507               | 0.987             |
| MeanVC2，每块1步 | 28–68                 | 1.020               | 0.971             |
| MeanVC2，每块3步 | 84–204                | 2.861               | 0.971             |

当前CUDA不可用。以上是2线程CPU、模型已加载且完成预热后的整句生成及声码器耗时；前端提取时间另存逐样本账本。运行时仍可能与评分进程竞争CPU，没有隔离硬件，不作为正式速度基准，不与P1历史GPU时间比较。这里处理完整音频文件，不是实时首包延迟测试。

“每块1步”不等于“整句1次调用”：MeanVC块长20帧，MeanVC2为12帧加4帧未来上下文，整句按块反复调用。MeanVC默认2步保留官方非均匀网格[1,0.8,0]；MeanVC2默认3步使用[1,2/3,1/3,0]。通过forward hook逐条核对实际调用数=块数×步数，没有将宣传NFE直接当整句调用预算。

两个系统均保留原生16kHz声码器、特征提取、归一化和缓存更新。MeanVC的FastU2++与本地文件逐字节一致；两代Vocos的文件hash不同，分别加载各自官方文件，没有跨模型替换。官方代码只做包命名空间隔离以避免导入训练器；MeanVC的远程WavLM请求改为读取现有同一权重，推理期间禁止网络连接。核心前向与采样函数未修改。

## 5. 解读边界

本轮最值得继续验证的是MeanVC2：每块1步的CER点估计为3.73%，低于B1整句1步的8.56%，目标相似度和T−S也更高；但CER差的聚类区间跨零，尚不能宣称可懂度收益已稳定成立。MeanVC两档内容指标均没有超过B1一步，虽然目标相似度更高，不能概括为整体胜出。MeanVC2的1/3步CER接近也不构成严格等效证明。

本轮可用于判断约14–18M的官方转换器在这些样本上的实际能力，以及本项目与成品系统的差距。即便外部系统更好，也不能直接归因于MeanFlow本身、单一结构、前端或损失；训练语料、权重、条件机制和声学链路同时不同。反之，某个开源配方某项指标较差也不能扩大为该方法普遍失效。

MeanVC2相对B1参数更接近，但其ASR前端更大，整系统规模和计算未完全匹配。自然度、源韵律、跨评分器稳定性及完整100对结果仍未覆盖；不能把CER和余弦分数当作MOS或人工身份判断。
