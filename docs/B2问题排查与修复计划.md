# B2 问题排查与修复计划

> 日期：2026-10-16
> 状态：排查已完成第一轮；本文中的代码修改、消融训练和全量复评尚未执行。
> 范围：优先处理 B2，不同时改变 B1/B3 的训练配方、共享网络或历史结果。

## 1. 结论与执行原则

当前证据支持：**这轮 B2 的平均速度学习出现退化，生成结果保留了明显的初始噪声影响；非零时间区间的 JVP 大误差是最值得优先验证的训练因素。**

但必须区分三件事：

1. **已确认的代码问题**：默认独立验证／测试的推理模式会让 B2 的 JVP 修正项失效；统一评估断点记录缺少完整身份校验。
2. **已观察到的模型问题**：真实 B2 checkpoint 的自重建误差及噪声敏感性较高。
3. **尚未证明的因果关系**：普通 MSE 缺少自适应加权是否导致本次 WER≈1，必须通过训练消融确认。

不要把“找到一种可疑训练差异”写成“已证明 MeanFlow 公式有 bug”；也不要把当前结果推广为“MeanFlow 不适合语音转换”。

### 本轮不一起修改的内容

- B1/B3 的训练 loss、优化器和采样策略。
- 共享条件编码器的 GroupNorm 与 padding 处理。
- B2 的路径方向、JVP 切向量及一步更新符号。
- 时间分布、等时间比例、学习率、batch size 等多个因素。

共享 padding 缺陷客观存在，但目前没有证明它解释了 B2 相对 B1/B3 的差距。它应作为后续独立实验，而不是混入第一轮 B2 修复。

| 模型 | 输出差异 RMS 范围 |

| B3   |         1.54–1.70 |

### 2.4 B2 的非零区间误差

使用五条本地语音、八组随机数，共 40 组训练目标诊断：

| 类型  | 样本数 | 平均样本 MSE |
| ----- | -----: | -----------: |
| `r=t` |     28 |         1.57 |
| `r<t` |     12 |        16.48 |

12 组非零区间贡献约 82% 的按样本 MSE 总和；最大单样本 MSE 为 136.27，对应 JVP 修正项 RMS 为 10.89。

这里统计的是有限诊断样本的误差，**不是全训练集分布，也不是梯度贡献占比**。但它给出了可检验的假设：普通 MSE 可能使少数大 JVP 误差区间主导优化。

### 2.5 已检查、暂不支持的简单解释

- 替换说话人向量、反转或清空内容特征，B2 输出都会改变，不支持“条件根本没接进去”。
- 在一个真实样本上将 B2 分为 5／50 段调用，没有恢复重建质量；不能把增加 NFE 当成已验证的修复。
- 当前路径、JVP 方向与一步更新前后一致，未发现简单翻转符号就能解决的问题。
- 现有相关模型测试 35 项通过，但原测试没有覆盖全部数值语义，因此不能把通过测试当作算法正确的充分证明。

## 5. 阶段一：先修正 B2 的 JVP 评估口径

### 步骤 1.1：先增加会失败的回归测试

在 `tests/models/test_conditional_mean_flow.py` 补充：

1. 固定非零区间，例如 `r=0.2, t=0.8`。
2. 用可解析网络验证 JVP 目标，而不仅检查形状和有限值。
3. 固定输入、参数与随机数，验证正常模式和 `no_grad` 下目标一致。
4. 覆盖默认独立 `Trainer.validate/test` 的实际入口，防止只在手工 `inference_mode=False` 的测试里通过。

解析网络可取：

$$
u(x,t,r)=2x+3t+5(t-r).
$$

固定 r 时沿路径的总导数应为：

$$
\frac{du}{dt}=2v+8,
\qquad
u_{\mathrm{target}}=v-(t-r)(2v+8).
$$

如果测试只使用 `r=t`，修正项本来就是零，无法检测本问题。

### 步骤 1.2：采用最小范围修复

优先在 `configs/experiment/conditional_mean_flow_vctk.yaml` 中设置：

```yaml
trainer:
  inference_mode: false
```

这会使该 B2 实验的独立验证／测试使用允许前向自动微分的上下文，而不改变 B1/B3 的默认训练配置。

注意：

- 保留现有 JVP 目标的 stop-gradient，不要通过允许目标分支反向传播来“修复”。
- 直接在外层 `inference_mode` 内调用 `compute_loss` 仍需要明确处理：可以拒绝该调用并给出清晰错误，不允许静默返回另一种 loss。
- 若选择内部退出推理模式的实现，必须测试输入本身是 inference tensor 的情况；不能只加一个上下文而不验证张量语义。
- B3 同样包含 JVP，后续应以同类回归测试单独确认并配置；不要以“当前 B3 生成较好”断言其 test loss 没有模式问题。

### 步骤 1.3：验收

已有真实 B2 权重在同一批次、同样八组随机数下，测得：

| 上下文              |    loss |
| ------------------- | ------: |
| 正常 JVP／`no_grad` | 26.4427 |
| `inference_mode`    |  1.5422 |

修复后，**受支持的独立测试入口应与正常 JVP 目标一致**；不要求错误上下文继续静默运行。历史日志中的 test/loss=1.6647 应标记为存在口径风险，不能与 val/loss 直接比较。

这个修改无需重训就能重新计算已有权重的正确损失，但不会自动改善已有权重的生成质量。

## 6. 阶段二：为 B2 增加可关闭的稳健加权

### 步骤 2.1：先固定参考实现，不直接照搬 B3

核对的作者实现为 `Gsunshine/meanflow`，文件 `meanflow.py`，对应文件提交 `58d099c0fa197bd31b9a7b51727a76019ae5fdbe`。

该实现包含按样本误差能量的自适应加权，并对权重停止梯度；默认 `norm_p=1.0`、`norm_eps=0.01`。它还支持不同时间分布，因此“使用 uniform”本身不能直接定性为 bug。

参考实现用于固定训练设计的来源，**不意味着所有超参数都能无差别搬到变长 log-Mel 任务**。本轮只改变损失加权，不同时改时间分布、等时间比例或优化器。

### 步骤 2.2：明确本项目的候选公式

建议在 `ConditionalMeanFlow` 中新增以下配置，旧配置缺省时保持原行为：

| 参数                    | 默认值 | 含义                                |
| ----------------------- | -----: | ----------------------------------- |
| `adaptive_loss_power`   |    0.0 | 0 表示关闭加权；第一轮候选使用 1.0  |
| `adaptive_loss_epsilon` |  0.001 | 按有效元素 MSE 尺度设置的正数保护项 |

令样本 i 的有效元素数为 N_i，掩码为 m：

$$
N_i=C\sum_f m_{i,f},
\qquad
q_i=\frac{\sum_{c,f}m_{i,f}(u_{i,c,f}-u^*_{i,c,f})^2}{N_i}.
$$

候选权重与优化损失为：

$$
w_i=\operatorname{stopgrad}\left[(q_i+\epsilon)^{-p}\right],
\qquad
L_{\mathrm{opt}}=\frac{\sum_i N_i w_i q_i}{\sum_i N_i}.
$$

原始未加权指标继续保留：

$$
L_{\mathrm{raw}}=\frac{\sum_i N_i q_i}{\sum_i N_i}.
$$

采用这个定义的原因：

- `p=0` 时数学上退化为当前按有效元素计算的 masked MSE。
- 权重依据有效元素均方误差，而非直接由语音长度决定。
- padding 不进入误差能量或有效元素数。
- 整个权重必须 detach；只停止 JVP 目标梯度不够。

**这是面向本项目变长序列的候选适配，不是作者固定尺寸图像实现的逐行复现。**

如果采用作者的误差求和形式，应单独命名实验并重新检查长度权重和梯度尺度，不能在两种定义间静默切换。

实现时建议让 `p=0` 直接调用现有 `masked_mse`，保证原始分支在浮点实现上也尽量保持一致。不得改变 `compute_loss` 现有四元组返回约定而不更新和验证调用方。

### 步骤 2.3：增加损失回归测试

至少覆盖：

1. `p=0` 与现有 `masked_mse` 的结果及参数梯度一致。
2. 权重和 JVP 目标都停止梯度，预测分支保留有限梯度。
3. 大误差样本被相对降权，不能只验证输出为有限值。
4. 修改无效 padding 数值，不改变损失和有效区域梯度。
5. 不同有效长度下的归一化符合上面的明确公式。
6. 非法 power、非正 epsilon 被拒绝；空有效掩码的合同明确且受测试保护。
7. 关闭新配置时，旧 checkpoint 严格加载，固定 seed 的生成结果不变。

### 步骤 2.4：不要把加权 loss 用作唯一质量指标

当 p 接近 1 时，加权 loss 的数值可能接近常数。**不能因为它变成约 1，就认为 B2 收敛或优于原模型。**

在 `VoiceFlowModule` 中为 B2 补充诊断日志，保持其他方法的行为默认不变：

| 指标                             | 用途                                         |
| -------------------------------- | -------------------------------------------- |
| `train/optimization_loss`        | 实际用于反向传播的目标                       |
| `val/raw_meanflow_mse`           | 固定采样下的未加权 MeanFlow 误差             |
| `val/velocity_mse`               | 与瞬时速度的误差，辅助区分局部学习与区间学习 |
| `val/nonzero_interval_mse`       | 非零区间单独统计，不能将空组记成 0           |
| `val/jvp_correction_rms`         | JVP 修正项尺度                               |
| `val/one_step_reconstruction_l1` | 固定验证样本的一步自重建诊断                 |

固定验证样本必须从验证划分选取。不要根据正式测试集的 WER、最佳 seed 或某几条测试样本来挑参数和 checkpoint。

控制组和加权组使用相同的 checkpoint 选择指标，例如 `val/raw_meanflow_mse`。这个新指标必须先在代码中实现，并复用固定采样规则；不能只修改 callback 名称，否则训练会因缺失监控指标而失败。

若阶段一已将 `inference_mode` 写入实验 YAML，上述参数应改为 `trainer.inference_mode=false`，不再带 `+`。每次新运行更换输出目录，不覆盖同名历史目录。

两组从相同初始化种子开始，不从旧 B2 checkpoint 恢复。旧权重微调只能算单独的补救实验，不能代替从头训练的受控对照。

不要在第一轮失败后同时改学习率、时间分布、padding 和 warmup。先分析单因素结果，再建立下一组明确命名的消融。

## 8. 阶段四：修复断点身份并重新生成

### 步骤 4.1：完善评估记录身份

修改 `src/analysis/unified_vc_evaluation.py`，为新输出目录保存不可变实验元信息，至少包括：

- checkpoint SHA256 与模型行为配置。
- 源码版本和未提交改动身份。
- 固定清单 SHA256、source/reference ID。
- 特征缓存版本或本次使用文件的指纹。
- NFE、基础 seed 和逐样本 seed。
- Mel 参数、dtype、计时设备与计时口径。

完成键不能只使用 `(experiment_id, source_id)`，必须关联 reference 与实验身份。参数不一致时拒绝续跑，不静默复用或混合；旧账本缺少身份时不要自动认作兼容。

`limit` 只是选择本次执行的样本范围：若完整清单与生成身份未变，应允许先跑 1 条再扩展到 100 条。计时设备改变后，不应继续把新旧 latency 混在同一聚合中。

### 步骤 4.2：补充断点回归测试

在 `tests/analysis/test_evaluation_reports.py` 中验证：

1. 相同身份续跑不重复生成。
2. 修改 checkpoint 内容、reference、NFE、seed、Mel 配置或缓存身份后拒绝误复用。
3. 从 limit=1 扩展到完整同一清单时只补齐缺失项。
4. 原目录与原账本保持不变。
5. 每个实验和样本在聚合中最多出现一次。

### 步骤 4.3：先单样本，再验证子集，最后正式测试集

现有 B2 checkpoint 的单样本 Mel 链路检查可使用：

```bash
python scripts/analysis/evaluate_unified_vc.py \
  --plan analysis_results/baseline_validation/experiment_plan.csv \
  --manifest analysis_results/baseline_validation/test_manifest.csv \
  --vctk-root /media/B8BE-8B5F/Tom/data/VCTK \
  --feature-cache-dir data/meanvc_features/vctk \
  --experiment-id nfe_b2_01 \
  --limit 1 \
  --device cpu \
  --output-dir analysis_results/b2_diagnosis_20261016_old_weight_smoke
```

这条命令仅验证旧权重链路，不证明新训练已经改善；运行前检查计划的 `run_dir` 是否仍指向目标历史 B2。

新控制组和加权组分别建立明确固定 `run_dir` 的计划，并使用各自独立输出目录。默认审计程序按标签选择最近运行，不能用它自动推断两个同为 B2 的消融应分别对应哪份权重。

现有统一评估的跨模型差异逻辑没有为多个 B2 变体提供明确消融语义，因此不要把多个同名 B2 塞进同一计划后直接相信差异表；先分别输出，再按相同 source/reference 配对比较。

用独立验证子集选择方案后，再对锁定的 100 组正式测试清单评估。每组使用相同多 seed 列表，例如 12345、23456、34567，并报告均值、离散程度与逐样本配对差异，不挑选最好的一次。

## 9. 阶段五：恢复波形评估证据链

### 步骤 5.1：先取回缺失材料

原结果文档提到的波形评估模块、入口脚本、全量逐样本指标和转写，当前工作区未找到。需从原执行环境取回：

- 实际运行的波形评估源码及版本。
- 逐样本 source/reference ID、参考文本、ASR 转写。
- WER/CER 的替换、删除、插入和参考长度统计。
- 声码器／ASR／说话人模型的具体版本与配置。
- 重建对照记录及生成波形。
- 对应 checkpoint、Mel 文件和断点记录的身份。

复制或下载前先确认许可。材料不足时，只能复核本地 Mel 与训练目标，不能宣称重现了历史 WER。

### 步骤 5.2：检查指标口径

1. 可懂度与 **source 文本** 比较；reference 主要提供说话人条件。
2. 同 sentence ID 不代表 source/reference 转录逐字一致，不能直接互换。
3. 明确采用语料级 WER，还是逐句 WER 的均值；同时保存原始编辑次数便于复算。
4. WER 大于 1 可以由插入错误产生，不能仅凭 WER≈1 宣称每个词都错。
5. 音频被截断时，不能不加说明地使用完整长文本作为真值。
6. ASR 失败、空转写和无效指标必须单独记录，不能静默丢弃困难样本。

### 步骤 5.3：固定声码器与重建对照

所有生成系统使用相同冻结声码器和相同 Mel 适配。先复核真实 Mel 的重建对照，再评估生成 Mel。

项目 log-power Mel 到声码器输入的除二与频带插值是近似适配，不能仅凭文字描述认定完全等价。保留适配前后统计和试听样本；不要只为 B2 更换声码器或单独调整适配参数。

### 步骤 5.4：判定训练修订是否有效

同时检查：

- B2 自重建和跨说话人生成是否都改善。
- 初始噪声相关性及 seed 敏感性是否下降，但不要求生成完全确定。
- WER/CER 是否相对控制组稳定改善。
- 说话人相似度、韵律是否出现新的退化。
- 一步 NFE、latency、RTF 是否维持目标口径。
- 多 seed 和逐样本配对结果是否支持均值结论。

**只有训练 loss 变小、Mel L1 变小或某一条试听改善，都不足以宣布问题解决。**

若稳健加权无效，应保留负结果，下一轮再单独研究时间分布、端点训练覆盖或条件设计。

## 11. 原结果文档应如何表述

原始数值保留，不把尚未验证的新结论覆盖进历史结果表。正式论文或结果总结中应调整以下表述：

- “MeanFlow 不适合 VC”改为“当前 B2 实现和训练设置下表现较差，正在排查训练与评估因素”。
- “WER≈1 说明转写全部错误”改为报告编辑次数与实际转写示例。
- “B3 改善证明伪源先验有效”改为“B3 多项设计共同变化后表现改善，单项贡献需消融”。
- B1 完整报告 1／5／10／50 NFE 曲线；不能因为某些指标支持 50 NFE，就把它设为唯一公平基线而忽略低 NFE 结果。
- “低 NFE 过平滑、高 NFE 引入伪影”等解释列为待验证假设，需频谱、试听或额外诊断支持。

最小闭环是：

**先修正评估 loss 口径，再对 B2 做可关闭的稳健加权与受控重训，最后在身份一致的评估链路上确认生成质量。**

共享 padding 改动另立实验，不与这个闭环混在一起。
