# 研究阶段总结与下一步决策

整理日期：2026-10-26。依据项目内已完成的训练、P1、P2 与 2026-10-24 端点覆盖 pilot；本次整理未新增训练或质量评估。

> 后续复核更新：已直接读取原论文并完成[B3 实现核对](../diagnostics/B3%E8%AE%BA%E6%96%87%E5%AE%9E%E7%8E%B0%E6%A0%B8%E5%AF%B9_20261026.md)，发现共享条件归一化的 padding 缺陷并修复，但质量收益未知。当前先核查复现缺口，暂缓将下文方向A作为论文主线；P4的相对趋势不能代表原论文固有机制。

## 1. 总体判断

已经完成基线建立、统一评估、机制诊断和第一次受控训练干预。MeanFlow 的完整端点 raw 残差很大，但增加端点覆盖后，相对 Control 的残差下降没有转化为可验证的转换质量收益。

当前应优先识别决定一步 VC 内容保持和目标身份形成的机制。暂缓 hidden=256、更多端点比例或直接追加双臂训练；这不意味着 MeanFlow 整体失效，也不排除其他配方有效。

## 3. P1：方法比较的结论

| 配置                        | 逐句平均 CER↓ | 目标相似度↑ |
| --------------------------- | ------------- | ----------- |
| B1，1 NFE                   | 7.44%         | 0.2878      |
| B1，5 NFE                   | 9.32%         | 0.3295      |

B2 内容指标弱于 B1 一步，但目标相似度接近。B3 没有整体改善 B2，源 F0 相关性却由 0.8945 提高至 0.9205，应单独解释。B1 增加步数时内容和音色指标方向不同，尚不能称为固有冲突。

以上只针对固定权重、100 对和一次固定生成噪声。完整协议、配对区间和声码器对照见 [P1 报告](../evaluation/P1%E6%9C%80%E6%96%B0%E4%B8%89%E7%BB%84%E7%BB%9F%E4%B8%80%E8%AF%AD%E9%9F%B3%E8%BD%AC%E6%8D%A2%E8%AF%84%E4%BC%B0.md)。

## 4. P2：异常观察与机制证据的边界

B2 的 raw MeanFlow MSE 随区间长度和位置显著变化；JVP 有限差分检查通过，条件替换也改变输出。基础公式错误或完全忽略条件不再是首要解释，但这不能排除其他实现或条件利用问题。端点 raw 残差与 CER 的 Spearman 相关约 0.037，区间跨零。

B3 原生损失分解均值：raw MSE=1.7619，adaptive 标量约 1，SSIM 项=0.4286，总 loss=1.4286。adaptive 项前向近乎常数仍有梯度，总 loss 的数值主要反映 SSIM，不能直接表示平均流预测改善。`last.ckpt` 与 epoch40 指纹相同，无法比较早期和真实末期质量。

| B3 source_time | CER↓   | 目标相似度 | 源相似度 | 目标−源 |
| -------------- | ------ | ---------- | -------- | ------- |
| 0.80           | 5.14%  | 0.3489     | 0.3491   | -0.0002 |
| 0.90           | 10.28% | 0.3445     | 0.2765   | 0.0680  |
| 0.95           | 14.90% | 0.3273     | 0.2268   | 0.1005  |
| 1.00           | 33.04% | 0.2996     | 0.1732   | 0.1265  |

这组数据来自 P2 的 64 对、每对两个噪声，不能与 P1 绝对分数直接比较。0.8−0.95 的 CER 差为 −9.77 个百分点，配对区间 [−16.18, −4.29]；目标−源相似度差为 −0.1007，[−0.1400, −0.0629]；绝对目标相似度差区间跨零。

因此已有证据是“源信息增强伴随内容改善和相对身份偏好减弱”，尚未证明绝对目标音色下降、直接复制源音频或不可避免的身份冲突。详见 [P2 报告](../diagnostics/P2%E6%9C%BA%E5%88%B6%E8%AF%8A%E6%96%AD%E4%B8%8E%E4%B8%8B%E4%B8%80%E6%AD%A5%E6%9C%80%E5%B0%8F%E5%AE%9E%E9%AA%8C.md)及[原始聚合表](../../analysis_results/p2_mechanisms_20261024/conversion/quality_summary.csv)。

## 5. P3：端点覆盖的受控负结果

两臂继承同一 B2 epoch382 权重、优化器和学习率状态，共用数据、裁剪、噪声及步数。Control 为 75% 零区间、25% 普通非零区间；Intervention 为 75%/23%/2% 完整端点。

| 指标               | Control | Intervention |
| ------------------ | ------- | ------------ |
| 固定组端点 raw MSE | 2477.33 | 2009.05      |
| 固定组 CER         | 16.32%  | 16.71%       |
| 固定组目标相似度   | 0.3565  | 0.3592       |
| 保留组端点 raw MSE | 2511.48 | 2172.58      |
| 保留组 CER         | 18.18%  | 18.24%       |
| 保留组目标相似度   | 0.3629  | 0.3630       |
| 梯度裁剪频率       | 53.74%  | 74.92%       |

端点 raw MSE 相对 Control 下降约 18.9%/13.5%，但相对初始模型的差值区间均跨零；质量差异区间也均跨零。raw 目标包含当前网络的 JVP，属于移动的自洽目标，不是直接生成误差。不能由此写成“输出预测已改善但评分不敏感”。

新增端点增加了优化压力，但缺独立裁剪消融，不能把裁剪认定为质量未改善的原因。结论仅限当前未加权配方、学习率轨迹、裁剪和 5000 步预算；未检出收益也不等于严格等效。完整配对区间见 [pilot 报告](../diagnostics/B2%E5%AE%8C%E6%95%B4%E7%AB%AF%E7%82%B9%E8%A6%86%E7%9B%96pilot_20261024.md)。

## 6. 后续决策与执行顺序

**继续研究，但先做现有产物的诊断，不扩展训练矩阵。**

| 顺序 | 工作                                                                                                               | 推进 / 停止条件                                                                                 |
| ---- | ------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------- |
| 1    | 复用 B3 的 0.8/0.9/0.95 波形与逐样本表；按源、目标说话人和长度检查 CER、目标/源相似度、T−S、目标偏好比例及配对变化 | 判断趋势是否集中于少数说话人或困难样本；不能只看总体均值                                        |
| 2    | 核实本地说话人元数据后做源/目标性别组合分层；定义参考质量标准，再做分层                                            | 元数据缺失时不从编号或 F0 推断性别；参考质量不能仅由同源相似度定义                              |
| 3    | 盘点本地独立说话人编码器，准备同一配对的随机盲听清单                                                               | 缺权重则先记录缺口，下载前另行询问；无人完成听测时不宣称通过                                    |
| 4    | 若身份趋势在独立评分/盲听中保留，提出“保源内容且减弱源身份”的单因素干预                                            | 预先固定指标、预算和失败条件；若独立验证不支持，停止把源身份泄漏作为主因                        |
| 备选 | 配对检查 B1 已有不同 NFE 的错误文本和音色变化                                                                      | 现有不同 NFE 终点输出只能定位样本；时间段归因需要额外保存中间状态或分段干预，不能直接从终点推断 |

方向优先级：A，源内容与目标身份解耦；B，面向一步输出质量的训练信号；C，B1 生成轨迹机制。B 仍需与已有重建、consistency 和蒸馏方法比较，不能只加 loss 就宣称创新。相关工作历史核查不等于新方案已完成查新。

新训练前应明确一个可证伪假设，例如：降低 source_time 的主要变化是否是源相似度增加，且在独立评分器和大多数说话人配对中仍导致 T−S 降低。先检验这一现象，再决定是否值得设计身份解耦训练；它本身仍不是因果证明。

## 7. 尚不能写入论文的结论

- 单训练种子与同源说话人评分器不能支持算法普遍优劣；验证集曾参与 checkpoint 监控，两个验证队列也共享说话人。
- B2 是未使用 adaptive weighting 的配方，不能代表完整 MeanFlow 配方的最优表现。
- B3 缺真正 epoch499 权重，不能判断末期选模失败。
- 现有速度不含完整在线前端，且 GPU 未隔离，不能声称整系统低延迟。
- 当前主问题已经从“谁的训练 loss 更低”推进到“一步输出如何同时保持内容并形成目标身份”；有效方法和论文创新点仍待验证。
