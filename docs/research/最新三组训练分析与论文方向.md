### 4.2 为什么接近 1.4 的 loss 不足以说明流学习效果

当前 [MeanVoiceFlow 实现](../../src/models/methods/generative/flow/mean_flow/meanvoiceflow.py) 的单样本 adaptive 项为：

$$
E_i=\sum_{c,f\in\mathrm{valid}}(\hat u-u_{\mathrm{target}})^2,\qquad
A_i=\frac{E_i}{\operatorname{sg}(E_i+10^{-3})}.
$$

当 $E_i\gg10^{-3}$ 时，**前向数值接近 1**；即使原始误差变化很大，该标量也可能几乎不变。但 denominator 已 detach，梯度为 $\nabla E_i/(E_i+10^{-3})$，并不等于对常数 1 求导。因此不能据此说“MeanFlow 分支没有梯度”或直接判定代码错误。

总目标是 $\operatorname{mean}(A_i)+\mathcal L_{\mathrm{SSIM,margin}}$，重构项权重为 1、margin 为 0.3。非空样本上的目标下界为 0.3；只有 adaptive 项接近 1 时，才可把 1.3 视为近似的饱和基准。训练最终约 1.307 **与该情形相容，但不能证明原始流误差已小或 SSIM 全部达标**。本轮没有记录两项分量，不能精确将 `loss−1` 认作 SSIM loss。

与 B2 不同，B3 本轮只记录了总训练/验证/测试 loss，没有 raw MSE、非零区间误差、JVP RMS 或一步自重建曲线。B2 的诊断不能外推成 B3 的实测结果。下一步应在固定验证批上分别测量这些量，尤其区分纯噪声与有效伪源分支。

## 5. B2 实现核查到什么程度

检查了 [conditional_mean_flow.py](../../src/models/methods/generative/flow/mean_flow/conditional_mean_flow.py)：

- 路径为 z_t=(1-t)x+tε，瞬时速度 ε-x；一步输出 ε-u(ε,0,1)，正反向约定一致。
- JVP 对状态、终点 t、固定起点 r 的切向量为 (ε-x,1,0)，interval=t-r 的导数也进入计算。
- JVP 目标停止梯度；r=t 时退化为瞬时速度；损失按有效帧掩码归一化。
- B2 `adaptive_loss_power=0`，明确是无 adaptive weighting 的消融基线，不是 MeanFlow 论文全部训练配方的忠实复现。

2026-10-21 的前次核查在 Lightning-Template 环境、CPU 上执行（本次未重跑）：

```bash
conda run -n Lightning-Template --no-capture-output env CUDA_VISIBLE_DEVICES= OMP_NUM_THREADS=1 pytest tests/models/test_conditional_mean_flow.py tests/models/test_voice_architecture.py -q
```

前次结果：**57 passed，3.46 秒**。覆盖解析 JVP、目标梯度、采样、固定 RNG、B3 伪源、SSIM 及 Lightning 小规模流程；三个最佳 checkpoint 均能 strict 加载当前模型。

结论边界：没有发现这些契约中的基础公式/方向错误，但单元测试与 strict 加载不能证明真实大模型的 GPU 数值、数据语义及全部评估完全正确，也不能证明当前工作树与开训时源码逐字一致。下一步应抽取真实批次核对输出、缓存匹配，并对比自动 JVP 与有限差分；不应为了“确认没错”先重训三组。

还有三个决定性的口径限制：

1. [vocoder_evaluation.py](../../src/analysis/vocoder_evaluation.py) 将生成波形与目标 `reference_waveform` 比较 F0/能量。它不是源韵律保真指标；不同说话人同一句话并无唯一的自然 F0 真值。现有结果不能证明“内容与源韵律必然冲突”。
2. [metrics.py](../../src/analysis/vocoder/metrics.py) 使用统一点数线性伸缩轮廓；未做细粒度语音对齐。F0 是否可靠、有声/清声判断、跨性别范围和失败值覆盖率都应核验，不能只看相关系数。
3. 旧“端到端 RTF”只是缓存条件 -> Mel -> 波形，不含离线内容/说话人编码器。它不能支持整条系统已经实时，也不能据此宣称生成器缩小后端到端等比例加速。

旧声码器对照：真实参考 ASR CER=0.0091，同一 Mel 适配链路重建 CER=0.0227，相似度=0.8204。说明链路存在损耗，但不能凭此断言它解释了全部模型差异；也不能把该有限样本的重建成绩当作所有模型的严格性能上界。

本轮 P1 已使用独立新目录并绑定三个运行的配置/权重指纹，没有向旧账本追加同名实验。B3 的 `epoch_040.ckpt` 是完整训练选出的最佳权重，已参加本次正式比较。旧评估还使用了不同的 Mel 适配，绝对分数不可直接混用。

## 8. 推荐算法假设应怎样落地

暂定问题：**有限容量的一步网络，是否需要不同于大模型的区间监督分配？** 先检验误差机制，再决定算法形式，不预设增加模块一定有效。

第一版只保留一个主变量：在原训练分布之外，以固定预算加入长区间/完整推理区间监督。明确这是改变训练目标，还是用重要性权重保持原目标；不能含混地称为无偏改进。对照最佳固定时间分布、B2 adaptive weighting、等计算量延长训练。只改 equal-time 概率属于调参，单独不足以支撑论文。

若端点不一致得到证实，可进一步测试训练期的分段终点一致性。定义同一条件 c 下的映射：

$$
G_{r\leftarrow t}(z,c)=z-(t-r)u_\theta(z,r,t,c).
$$

比较直接映射与固定分割点 s 的复合映射：

$$
\mathcal L_{\mathrm{end}}=
\left\|G_{0\leftarrow1}(z,c)-
\operatorname{sg}\left[G_{0\leftarrow s}(G_{s\leftarrow1}(z,c),c)\right]\right\|_1.
$$

这是**待查新、待验证的辅助约束候选**，不是新颖性声明，也不是数学恒等式自动保证的正确预测。若扩展到 B3，需固定并正确传递同一个 source_time、条件和起点分布；不能把伪源训练路径当纯噪声路径直接替换。

该项只在训练增加网络调用，最终推理仍为一次；必须报告增加的训练算力。自举目标可能有偏差或坍塌，应保留原目标，使用 detach 或明确的 EMA 协议，并对照普通自重建、已有 consistency/shortcut 类方法。没有外部教师不等于没有自蒸馏。若复合路径本身更差，不能把它当可靠监督。

**能力目标示例，不是已有结果或保证：** 生成器从约 18.9M 降到约 5M 参数，1 NFE 不变，实测 CPU/GPU 耗时下降，并以预先定义的非劣效界保持 CER、目标相似度和源韵律。非劣效阈值需由基线方差和应用需求决定，不在看到测试结果后选。

只改变 B3 hidden_channels、其余结构不变时，CPU 实例化计数如下；尚未训练，也未测速度/质量：

| hidden_channels | 生成模型参数 | 相对 512 的参数减少 |
| --------------: | -----------: | ------------------: |
|             512 |   18,873,376 |                  0% |
|             384 |   10,829,216 |            约 42.6% |
|             256 |    5,013,280 |            约 73.4% |

参数减少不保证同等比例加速；若前端或声码器主导总耗时，应收窄为“轻量生成器”，不宣称整系统极低延迟。

## 10. 评价与失败判据

- 内容：CER/WER、逐句识别文本和盲听；排查静音、音量、裁剪、拉伸及 ASR 失败。若只在 Whisper 上改善，独立 ASR/听测不改善，不宣称内容能力提升。
- 音色：目标相似度、源相似度/泄漏、跨性别与参考质量分层。只提高源相似度或复制源 F0 不能算成功转换。
- 韵律：先定义保源还是模仿目标；保源任务单独计算源归一化 log-F0 轮廓、清浊音、能量与时长，避免绝对音高泄漏与目标音色混淆。对齐方式和有效样本数必须报告。
- 自重建：用于检验条件和声学输出，不可替代 unseen-speaker conversion；Mel L1 低也可能只是输出更平滑。
- 声码器：保留统一现有链路和重建对照；可在条件允许时补充更匹配链路，但不把换声码器设为当前算法诊断的先决条件，也不未经允许下载。
- 效率：分别报告生成器、含前端、完整波形链路，目标参考冷启动和可缓存情况分开；用相同精度、batch、音频长度和热身，训练 GPU 忙碌时不采集最终速度结论。
- 放弃 H1：区间分桶不支持瓶颈，或 candidate 只降自己的加权 loss、不改善转换，或优势全部来自更多训练算力，则停止该路线。
- 放弃“小模型专用”解释：容量降低没有额外放大该问题，或收益无容量交互；可以转为通用训练改进，但需另做新颖性和强基线验证。
- 放弃“内容韵律冲突”解释：改用源参照/可靠 F0、合理对齐和独立 ASR 后趋势消失，则将旧趋势视为评价/生成链路效应，而不是写成固有矛盾。

## 11. 论文叙事与当前不能写的结论
