## 2. 已有机制，不能冒充创新

以下采用原论文时间方向：$z_t=(1-t)x+t\epsilon$，从 $1$ 到 $0$。这是公式说明，不判断本地时间约定是否正确。\[R2 §2.1 式 (1)，<https://arxiv.org/html/2602.18104v1#S2.SS1>\]

| 机制             | 已核实的论文事实                                                                                                                                                       | 原文定位与 URL                                                                              |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| 平均速度、JVP    | MeanFlow 用区间平均速度；目标为 $u_{\mathrm{tgt}}=v_t-(t-r)D_tu_\theta$，$D_tu$ 以切向量 $[v_t,0,1]$ 的 JVP 计算，目标停止梯度。JVP 是训练机制，不是一步推理额外迭代。 | R1 §4.1 式 (3)、(6)、(8) 至 (11)、Algorithm 1；<https://arxiv.org/html/2505.13447v1#S4.SS1> |
| Adaptive loss    | MeanVoiceFlow 使用 $d(a,b)=\|a-b\|^2/\mathrm{sg}(\|a-b\|^2+10^{-3})$；以 0.75 概率令 $r=t$。                                                                           | R2 §2.2 式 (5) 后；<https://arxiv.org/html/2602.18104v1#S2.SS2>                             |

| 扩散源与时间条件 | 推理输入 $(1-t')x^{\mathrm{src}}+t'\epsilon$，默认 $t'=0.95$；训练也引入扩散源，并额外条件化 $t'$。                                                                    | R2 §3.3；<https://arxiv.org/html/2602.18104v1#S3.SS3>                                       |

解释与边界：stop-gradient 分母不能在求导时与分子约去；因此不能因损失标量近 1 就宣称该项无效。这是上述公式的直接数学解释，不是本地观测。SSIM 窗口、mask 等实现细节，本次没有官方代码逐行证据，不能声称完全等价。

建议排除的贡献表述：新增 JVP、adaptive loss、SSIM margin、半批伪源、源扩散时间条件；将 MeanFlow 简单条件化；只更换已有特征；只缩窄网络。前五项已由上表覆盖；后几项必须另有明确问题、机制和受控结果，不能仅凭组件组合宣称首创。

## 4. 三个候选问题：均为建议，未经实验

### Q1. 小模型是否需要容量相关的区间训练分配？

**问题与假设**：固定 MeanVC 特征、1-NFE 和参数预算后，小网络的长区间平均速度误差是否集中于特定时频区域？若是，容量相关的区间采样/结构损失分配能否优于直接缩窄 B3，而不引入教师？不是先假定小模型必然有该问题。

**最小实验建议**：先比较完整/缩小 B2、B3；再在同一小网络中只改变区间分配，最后单独检验时频损失。固定数据、训练算力和推理预算；对照普通采样、已有 adaptive loss、等算力延长训练。改变采样分布时明确是改变目标还是使用重要性校正，不能混写。

**成功/失败判据建议**：报告参数、MACs、显存、解码耗时及内容/音色/韵律前沿；若改善仅来自更多训练计算、仅降自身加权 loss，或大模型同样改善而无容量交互，则“小模型专用机制”的解释不成立。未获得波形时只能报告 Mel 域结果，不能声称感知能力提升。

**新颖性风险**：MeanFlow 已研究时间采样与 adaptive weighting，MeanVC 已定位轻量化；仅调概率或权重属于调参。需证明容量与误差分配的可重复交互，并继续检索相关目标设计。\[事实依据：R1 §5.1 的 Time Samplers/Loss Metrics、附录 B.2，<https://arxiv.org/html/2505.13447v1>；R3 §2，<https://arxiv.org/html/2510.08392v1>\]

### Q2. 源信息强度能否改善内容/音色/韵律的三方权衡？

**问题与假设**：在固定特征与一步网络下，按语音片段置信度/清浊音状态选择源保留强度，能否优于一个全局扩散系数？建议优先试整句可学习标量或低分辨率门控，不直接声称“解耦韵律”。

**最小实验建议**：对照验证集选定的最佳固定系数、随机系数、等参门控、归一化 F0 条件；原 B3 的 SSIM/伪源/adaptive loss 均保留。若使用逐帧噪声比例，训练须覆盖该输入分布并条件化门控，重新说明路径及 JVP 中哪些条件固定，不能把原标量推导直接套用。

**成功/失败判据建议**：同一源与多目标交叉测试；同时测独立 ASR 的 WER/CER、目标相似度及源音色泄漏、归一化 log-F0 轮廓/清浊音/能量/时长，辅以盲听。预先定义是保源韵律还是转目标韵律。若只是照抄源音高、牺牲目标音色换内容分数，或没有超过最佳固定系数前沿，则否定假设。

**新颖性风险**：MeanVoiceFlow 已扫混合系数并检验鲁棒性，StreamVC 已用 whitened F0；FasterVoiceGrad、MeanVoiceFlow2 也处理内容/音色。因此不能宣称首次保韵律或首次减轻泄漏。\[事实依据：R2 §4.2、Fig. 3，<https://arxiv.org/html/2602.18104v1#S4.SS2>；R10 Abstract，<https://arxiv.org/abs/2401.03078>；R5 §3、R6 §3，URL 见上表\]

### Q3. 固定 lookahead 下，平均速度的跨块一致性约束是否有额外收益？

**问题与假设**：同一全局时间位置、相同噪声和条件，在不同分块偏移下的一步终点应尽量一致；这种训练期约束能否降低短 chunk 边界错误，而不增加推理 NFE 或未来上下文？这是候选实现，不是已证明的新方法。

**最小实验建议**：先建立真正有限上下文的前端/解码器/声码器预算，再比较无约束、普通 Mel 边界损失、简单 overlap-add、平均速度导出的终点一致性。共享重叠区噪声，避免把不同随机样本硬拉成一样；保持 lookahead、历史长度及计算量一致。

**成功/失败判据建议**：在多个 chunk 大小及随机切分偏移下，检查边界附近内容错误、F0 跳变、音色漂移与盲听，并报告端到端首包 p50/p95、稳态 RTF、峰值内存。若收益来自多看未来、更多重叠重算或后处理平滑，不能归因于平均速度约束。

**新颖性风险**：MeanVC 已有跨块历史条件，MeanVC 2 已解决短块上下文不足；“chunk consistency”本身也不能宣称首创。需要证明针对平均速度的约束在强边界损失和 FRC 类方案之外仍有增益。\[事实依据：R3 §2.2，<https://arxiv.org/html/2510.08392v1#S2.SS2>；R4 Introduction，<https://arxiv.org/abs/2606.09050>\]

另需区分：MeanFlow 原文已讨论流时间区间的可加性/一致性；本问题建议检验的是音频分块偏移下的预测一致性，不是把前者重新命名。\[R1 §4.1 式 (3) 后；<https://arxiv.org/html/2505.13447v1#S4.SS1>\]

## 5. 建议的证据门槛与未解决项

建议优先验证 Q1 的误差假设，再考虑 Q2；Q3 涉及整条流式链路，成本最高。此顺序是研究规划判断，不是本地模型优劣结论。

- 建议区分三种预算：只算生成器、包含特征提取、完整波形系统；参考音色可缓存与冷启动应分别报告。1-NFE 不等于低首包延迟，也不等于整个音频只调用网络一次。
- 建议蒸馏对照单列教师预训练、合成数据与学生训练成本；相同主干/特征内比较用于机制归因，不同官方完整系统用于能力定位，不能混为公平消融。
- 建议预注册非劣效界、随机种子、固定转换配对；按说话人/句子聚类计算区间，避免将大量相关转换当独立样本。阈值由基线波动确定，本次不虚构数值。
- 未解决：未证明三个具体候选在全部 VC、SVC、TTS、通用 MeanFlow 文献中不存在同构设计；定向检索不是全面查新。还需细查区间采样/频带损失、可学习源强度和跨块 flow-map 一致性的最近工作。
- 未解决：MeanFlow 官方仓库已链接 improved MeanFlow、pixel MeanFlow；本次未展开其论文，不能宣称原始 MeanFlow 是截至核查日最强训练目标。\[来源：官方 README 的 Update；<https://github.com/Gsunshine/meanflow>\]
- 未解决：MeanVoiceFlow 作者项目页未发现代码入口；这不是“作者没有发布代码”的证明。本次不能核验官方 SSIM 窗口、数值稳定项或完整实现等价性。\[检索范围：<https://www.kecl.ntt.co.jp/people/kaneko.takuhiro/projects/meanvoiceflow/>\]
- 未解决：没有本地端到端耗时、音质、内容、音色或韵律证据；缓存特征评估不能回答实时前端瓶颈。论文报告的速度与质量均不能外推给 Paper1。
