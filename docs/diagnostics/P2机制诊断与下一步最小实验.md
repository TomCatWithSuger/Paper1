## 1. 结论与完成边界

- **D1 完成。** B2 的长区间/完整端点存在真实的大残差，JVP 数值校验通过。更准确的描述是“端点与区间共同影响”，不能只讲跨度。残差与转换 CER 的关联没有得到支持，更没有因果证明。
- **D2 完成目标分解和伪源审计，末期质量比较无法完成。** `last.ckpt` 与 `epoch_040.ckpt` 的完整 SHA-256 相同，内部 epoch=40、global_step=45182。用户确认没有其他末期权重。它不能代表 epoch 499；无法判断验证 loss 选模与末期转换质量是否一致。
- **D3 完成。** source_time 从 0.95 降至 0.8，CER 从 14.90% 降到 5.14%；但目标与源音色相似度趋于相等。稳定取舍是“内容/源信息保持”与“相对源身份的目标偏好”，不是已经证明内容与目标绝对相似度冲突。
- **方向判断：暂缓将“紧凑一步 MeanFlow 的区间感知训练”作为确定论文主线。** 只保留一个同宽端点覆盖的最小反证试验；通过后才继续容量缩减。当前没有小模型、容量交互或区间误差导致质量下降的证据。

实际导出：4096 条区间记录、16 条内部时间点与16条端点的数值校验、B3 每个权重文件128条损失分解、1024条有效配置转换、128条原音/重建对照。末期权重别名不计作独立模型。

### 3.1 JVP 数值校验

真实变长微批，方向为 `(v,1,0)`，r固定；FP32禁用TF32。内部r=.2,t=.7、16源语句、4档h，主h=.001的最大相对L2=0.002290，最小cosine=0.999997，全部通过预设5%/0.99门槛。

完整端点r=0,t=1另用**域内二阶后向差分**，不需要t>1：16源语句、4档h，主h=.001最大相对L2=0.022107，最小cosine=0.999840，通过。巨大端点JVP并未被此次差分校验推翻。

4条真实语音的精度对照中，h=.001时有限差分相对误差均值：完整FP32约0.001991，TF32约0.293872；但TF32与FP32自动JVP本身仅约0.15%–0.18%偏差。小步长放大TF32量化误差，**不能据此称自动JVP公式错误，也不能认定TF32解释了P1质量差距**。

### 3.3 区间残差是否导致转换差？

完整区间的共同帧raw误差与转换CER，按64源先平均噪声：Spearman=0.037，区间[−0.376,+0.460]；控制log时长后的偏相关=0.084，区间[−0.326,+0.436]。JVP修正RMS与CER的Spearman=−0.026，区间也跨零。

**本次未检出稳定关联，也未证明不存在关联/因果。** raw指标是自身说话人重建路径，而CER是跨说话人转换；参考差异、语句难度和有限样本仍会影响关联。更关键的是raw目标包含JVP，真正一步输出`ε−u(ε,0,1,c)`不调用JVP。raw大与CER差同时存在，不等于前者导致后者。

这些结果不支持本次验证协议存在普遍伪源不足；无法据此还原历史训练shuffle的回退次数，也不能解释先前日志警告的频率。

## 7. 唯一建议的最小训练试验（本次未执行）

**同宽B2的端点覆盖受控pilot，先不缩窄网络、不叠加新loss。** 两臂都从同一epoch382权重和优化器状态起步，512通道，固定数据顺序、噪声、学习率轨迹、5000个更新步与现有梯度裁剪，保留现有未加权目标和全部条件链路。

- 对照臂：原75%零区间、25%原均匀非零区间。
- 唯一改动臂：75%零区间不变；非零分支中8%改为(r,t)=(0,1)，即总体2%完整端点、23%原非零分布。

这是有意改变训练采样分布，不称作原目标的无偏估计。计算次数不增加；记录端点分支梯度与裁剪频率，避免大JVP目标悄然支配更新。先核验新训练能保存**互异且epoch/global_step正确**的中间与末期权重。

在冻结验证协议及本次未用于转换扫描的剩余验证语句上，主要看CER、目标相似度和T−S，而不是仅看新分布下的loss。若只是端点raw误差下降，转换不改善，或收益由源身份残留换来，则不继续该采样方案。若有方向一致的质量收益，再考虑后续容量交互验证；本次不启动任何训练。

**明确判断：当前暂缓“紧凑一步MeanFlow的区间感知训练”作为论文主线，只保留上述一次同宽机制反证pilot。** D1支持端点异常存在，却未建立质量因果；D2缺末期权重；D3提供有效的推理取舍但不是新的训练算法。此时直接训练小模型并包装容量专用方法，证据不足。
