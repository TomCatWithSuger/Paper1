# P4：B3 源身份残留验证

> 后续原论文核对发现共享条件归一化缺陷及完整系统复现缺口，见[B3 实现核对](B3%E8%AE%BA%E6%96%87%E5%AE%9E%E7%8E%B0%E6%A0%B8%E5%AF%B9_20261026.md)。本页分数仍成立于历史适配系统；目前优先解释复现偏差，暂不把源身份泄漏视为已确定主因。

日期：2026-10-26。已完成现有评分器的细分复核、CAMPPlus 独立编码器交叉评分与盲听准备；人工听测尚未执行。独立评分支持“源强度增加伴随源相似度上升和相对目标偏好减弱”，但不支持直接写成“目标身份转换失败”或已证实的泄漏因果机制。

## 1. 输入与协议

复用 P2 保存的 `source_time=0.8/0.9/0.95` 音频：64 个源语句 × 两个固定噪声 × 三配置，共 384 条。三配置逐项核对源/目标、原文、噪声种子及波形存在性；输入表、真实源/目标/同说话人其他语句、生成音频及说话人元数据保存 SHA-256。

性别标签来自本地 VCTK `speaker-info.txt`，只使用其 M/F 元数据，未从声音推断。性别组合样本量为 F→F 23、F→M 13、M→F 15、M→M 13 个源语句；16 个源说话人、37 个目标说话人。性别分层是描述性核查，不解释为性别因果效应。

先在每个源语句内平均两个噪声的分数，再做配对差；目标偏好比例先对每个输出计算 `T>S` 后平均。区间按源说话人和实际文本乘积重采样 2000 次；未校正多重比较，不涵盖训练种子方差。目标说话人的结果主要作为描述，部分目标样本稀疏，不能视作独立复现实验。固定随机种子为 20261026，因此与 P2 区间的末位略有差异。

## 3. CAMPPlus 独立编码器交叉验证

本地发现可复用的权重：

```text
/mnt/data2/home/tsx/project/TTSLab/TTS/pretrained_models/CosyVoice2-0.5B/campplus.onnx
```

CAMPPlus 架构不同于当前条件前端和评分器的 WavLM+ECAPA。它可以提供编码器层面的交叉验证，但其训练语料独立性尚未核实，不能称作完全独立的数据证据。

已按本地 CosyVoice 代码实现 16kHz 单声道、80 维 Kaldi fbank、dither=0 和逐维去时间均值。真实源/参考使用原始 mic1 音频重采样；生成使用现有 WAV；全句处理，不随机裁剪。该链路与旧评分器的 22050Hz 中间链路不同，相似度绝对值也不可跨评分器比较。

经下载/安装审批后，已在现有 `Lightning-Template` 环境安装 `onnxruntime==1.23.2` 及缺失依赖 `coloredlogs`、`humanfriendly`、`flatbuffers`；没有下载模型、创建环境或启动训练。推理使用 CPU、单线程，完成 384 条生成语音和 96 条真实语音的 480 个向量。

权重 SHA-256：`a6ac6a63997761ae2997373e2ee1c47040854b4b759ea41ec48e4e42df0f4d73`。实际代码、预处理和版本见[运行审计](../../analysis_results/p4_identity_20261026/campplus/COMPLETE.json)。

真实音频对照：64 对中，62 对的同说话人不同语句相似度高于跨说话人相似度（96.875%）；均值分别为 0.6975 和 0.3505。这支持基本身份区分能力，不代表生成语音上的评分完全可靠，也不是感知质量验证。

补充的三向聚类使用 5000 次重采样，进一步考虑目标说话人复用。两个编码器的源相似度上升和 T−S 下降均保留；CER 沿用同一份 Whisper 结果，不是独立 ASR 复核。CAMPPlus 的 T>S 比例差为 −14.84 个百分点，但三向聚类区间为 [−38.41, 0.00]，不把该二值指标单独写成稳定退化。

CAMPPlus 的 T−S 在 64 个源语句中的 58 个、16 个源说话人组中的 15 组、37 个目标说话人组中的全部 37 组下降；源相似度在 61/64 个源语句上增加。性别组合的 T−S 差如下，分层区间采用前述两向口径：

| 组合 | T−S差   | 95%区间            |
| ---- | ------- | ------------------ |
| F→F  | -0.0920 | [-0.1157, -0.0675] |
| F→M  | -0.0581 | [-0.1188, -0.0108] |
| M→F  | -0.0432 | [-0.1069, +0.0074] |
| M→M  | -0.1350 | [-0.1838, -0.0784] |

**关键修正：CAMPPlus 下，0.8 仍有正的平均目标优势，而原 WavLM+ECAPA 下接近零。** 相对趋势跨编码器保留，绝对身份判断却依赖评分器。不能再将“0.8 的目标身份优势消失”泛化为独立评价共识；T>S 也不是经校准的身份识别正确率。

目前更准确的解释是源身份相关的声学影响增强。相似度也可能受 F0、内容、录音条件或生成伪影影响，尚不能把分数变化完全归因为音色泄漏，更不能确认它是质量的主要瓶颈。

## 4. 盲听准备

已按四个性别组合各随机抽四个源语句，共 16 组、48 个候选，固定使用噪声0。每组随机排列三个配置，候选 WAV 匿名命名，另保存原始源和目标参考供比较。

受试者只分发 `listening/README.md`、`listening/participant.csv` 与 `listening/audio/`，不要分发 `organizer_key.csv`。评分表预留转写、目标相似度、源相似度和自然度；第一轮只听候选并提交转写，之后才听源/目标参考做身份评分，避免源音频泄露文本而影响可懂度判断。每位受试者独立填写，保存受试者编号和完整评分，揭盲后按源语句聚合，避免把多个候选或受试者当独立源语句。当前没有人完成听测，因此没有听测结果。

## 5. 复现入口与决策

```bash

python scripts/analysis/evaluate_p4_identity.py --stage analyze --output-dir analysis_results/p4_identity_20261026
python scripts/analysis/evaluate_p4_identity.py --stage score --output-dir analysis_results/p4_identity_20261026 --campplus-model /mnt/data2/home/tsx/project/TTSLab/TTS/pretrained_models/CosyVoice2-0.5B/campplus.onnx

```

`analyze` 要求新输出目录，已完成目录不要重复运行；`score` 要求依赖已安装，先核验输入指纹，写入独立的 `campplus/`，不覆盖 P2。`sensitivity` 在两份评分完成后补充总体三向聚类区间。各阶段均阻止网络连接，不加载 VC 模型、不训练、不重新生成音频。已有独立评分和敏感性结果也不允许覆盖。
