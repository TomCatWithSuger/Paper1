# B2 完整端点覆盖：5000步双臂受控 pilot

执行日期：2026-10-24；GPU0，与现有任务共享。两组各5000次更新已完成。仅训练Control与Intervention，没有添加SSIM、终点一致性或其他辅助loss，没有下载或替换预训练模型。

## 1. 结论

**这次pilot没有显示内容与目标音色的共同改善，不建议继续hidden=256容量实验。**

1. **完整端点raw误差相对Control下降**：P2固定组约−18.90%，保留组约−13.49%，配对区间均不跨零。但相对初始epoch382仅约−3.02%/−3.40%，区间均跨零，不能称为解决了端点困难。
2. **内容没有改善证据**：Control→Intervention的CER为16.32%→16.71%（P2固定组）、18.18%→18.24%（保留组）；WER两队列方向不同，全部质量差异区间跨零。
3. **目标音色没有稳定改善证据**：相似度差分别+0.00273和+0.00002，区间跨零。不能把极小点估计变化写成有效收益。
4. **未检出源身份残留稳定增加**：源相似度及T−S变化均很小、区间跨零；这不是源残留不增加的非劣效证明。
5. **端点raw改善没有转化成已验证的转换收益**。这支持继续区分目标自洽误差与实际输出质量，不支持在该证据下扩大紧凑模型训练。

以上只针对同一初始权重、这一共同随机计划、2%完整端点覆盖和5000步预算；不能据此证明所有端点训练方法无效。

## 5. 验证协议与统计

只评估固定5000步末期，不按中间验证分数选权重。另重新评估原epoch382作为推理前测，**不是第三个训练臂**。

- P2固定组：原64对、16源说话人，每对两个原固定噪声；源长度2.09–5.59秒。
- 保留组：另64对，同16位源说话人，所有源/参考ID均排除P2已用96条ID，全部在原验证划分；含10条≥6秒语音，最长9.89秒。配对在训练前固定。
- 两队列源/参考/替换均与训练和测试样本ID互斥；说话人与原训练说话人重叠。原验证集也曾用于选择epoch382，不能称为完全未使用的外部数据。
- 共3份权重×2队列×64对×2噪声=768条转换，1536条零/完整区间诊断。冻结P2同一Mel适配、Vocos、Whisper-small、WavLM+ECAPA和NCCF源韵律口径。参考F0单列，不当作源F0。

配对区间先在源语句内平均两个噪声，再对源说话人与真实文本分别重采样、乘积加权，2000次。每队列64个源单位，不把128个噪声输出当独立语句；未校正多重比较。这里只有一个训练随机计划，区间不包含跨训练种子的方差。两验证组共享说话人，不是两个独立域。

## 9. 是否继续hidden=256？

**不建议基于本次pilot继续hidden=256容量实验。** 2%完整端点覆盖在同宽模型中降低了相对Control的raw端点残差，但没有内容与目标音色的共同收益，未通过训练前设定的扩展条件。

已证实的是：这一采样干预改变了学习到的端点自洽残差及梯度/裁剪分布。未证实的是：原先的巨大raw端点误差导致转换差，或缩小模型后该干预更有价值。结果只适用于当前未加权目标、原LR轨迹、裁剪1.0与5000步预算，不排除其他预算/配方可能不同，但本次不补跑其他比例、loss或训练臂。

当前应保留这次受控负结果，暂不把“紧凑一步MeanFlow的区间感知训练”作为已验证论文主线，也不将本结果扩大为整个MeanFlow方法失效。
