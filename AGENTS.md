## py代码模版

文件结构是这样，同理，class内部的函数也可以使用类似的结构。

```python
"""
模块说明：
- 这个文件负责什么
- 对外提供什么能力
"""

# ====================
# 1. Imports
# ====================

import ...


# ====================
# 2. Definitions
# 常量 / 配置 / 类型
# ====================

DEFAULT_XXX = ...


# ====================
# 3. Utilities
# 通用工具函数
# ====================

def _format_xxx(...):
    ...


def _validate_xxx(...):
    ...


# ====================
# 4. Internal Functions
# 内部业务 / 功能实现
# ====================

def _process_xxx(...):
    ...


def _handle_xxx(...):
    ...


# ====================
# 5. Core Logic
# 核心流程
# ====================

def _execute(...):
    ...


# ====================
# 6. Public API
# 对外提供的函数
# ====================

def run(...):
    return _execute(...)


# ====================
# 7. Entry Point
# 可选：直接运行该文件
# ====================

if __name__ == "__main__":
    run()
```
